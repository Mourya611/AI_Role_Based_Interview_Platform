# Data Structures & Software Engineering Fundamentals

## Time and Space Complexity Analysis
Big-O notation quantifies upper bounds of algorithm growth rates:
- O(1): Constant time (Hash map key lookup).
- O(log N): Logarithmic time (Binary search on sorted array).
- O(N): Linear time (Single pass array scan).
- O(N log N): Linearithmic time (Merge sort, Quick sort average case).
- O(N^2): Quadratic time (Nested loops).

## Object-Oriented Design (SOLID Principles)
- Single Responsibility: A class should have one reason to change.
- Open/Closed: Software entities should be open for extension, closed for modification.
- Liskov Substitution: Subtypes must be substitutable for their base types.
- Interface Segregation: Client-specific fine interfaces over general interfaces.
- Dependency Inversion: Depend on abstractions, not concrete implementations.
